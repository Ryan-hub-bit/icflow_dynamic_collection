# Experiment E1: Docker smoke test for claim C1

E1 checks the following claim on one included binary, `testlink`:

> ICFlowNet supports static and dynamic ICF ground-truth generation and
> angr-based heterogeneous ACFG construction from stripped binaries.

The reviewer needs only Docker. No repository checkout, compiler, Python
environment, GPU, or LLM test generation is required. Allow about 25 GB of free
disk space because the image contains the prebuilt LLVM, Pin/MyPinTool, and
ICFlowNet graph environment.

## Run E1

```bash
docker pull ghcr.io/ryan-hub-bit/icflow-dynamic-collection:e1

docker run --name icflownet-e1 --init \
  --cap-add=SYS_PTRACE \
  --security-opt seccomp=unconfined \
  ghcr.io/ryan-hub-bit/icflow-dynamic-collection:e1 \
  /opt/icflownet-e1/run_e1.sh --sample testlink --output /output/testlink
```

The second command performs the complete experiment and verification. A failed
check stops the command and returns a nonzero exit status. A successful run ends
with exactly:

```text
E1 PASS: static GT, dynamic GT, and stripped-binary heterogeneous ACFG verified for testlink
```

## What is verified automatically

The runner:

1. compiles `testlink` with the prebuilt custom LLVM and extracts nonempty
   compiler-label static ICF ground truth;
2. executes both indirect-call paths with Pin/MyPinTool and produces nonempty
   dynamic ICF ground truth;
3. verifies that the static and dynamic source-target pair sets are equal after
   basic-block normalization;
4. strips a copy of the binary, proves that stripping did not change its `.text`
   bytes, and confirms that the symbol table is absent; and
5. constructs the heterogeneous ACFG from that stripped copy with angr/DGL and
   checks for code nodes, data nodes, control-flow relations, and code-to-data
   edges.

The tested result is two matching static/dynamic ICF pairs and a graph with 35
code nodes, 5 data nodes, and 62 edges, including 12 code-to-data edges.

## Optional: keep the evidence

After the run, copy the report and generated files to the current directory,
then remove the stopped container:

```bash
docker cp icflownet-e1:/output/testlink ./e1-output
docker rm icflownet-e1
```

The concise machine-readable result is `e1-output/verification.json`. The full
command log is `e1-output/run.log`; generated static GT, dynamic GT, stripped
binary, and graph are in the same directory.
