# Experiment E1: package-based C1 smoke test

E1 tests ICFlowNet claim C1 on the real Arch Linux
[Zydis PKGBUILD](https://gitlab.archlinux.org/archlinux/packaging/packages/zydis.git),
pinned to commit `b24321b2f1041af560173d8036541fc8c376b849`. Zydis and
[Expat](https://gitlab.archlinux.org/archlinux/packaging/packages/expat.git)
form the validated package set; E1 uses one Zydis test binary to keep the review
short. It does not use `testlink` or LLM test generation.

The reviewer needs Docker, an x86-64 Linux host, Internet access, and about
25 GB of free disk. The image contains the custom LLVM, Pin/MyPinTool, and the
angr/DGL graph environment.

## Run

```bash
docker pull ghcr.io/ryan-hub-bit/icflow-dynamic-collection:e1

docker run --name icflownet-e1 --init \
  --cap-add=SYS_PTRACE \
  --security-opt=seccomp=unconfined \
  ghcr.io/ryan-hub-bit/icflow-dynamic-collection:e1 \
  /opt/icflownet-e1/run_e1.sh --sample zydis --output /output/zydis
```

The runner automatically:

1. fetches the pinned Zydis PKGBUILD and compiles it with the custom LLVM;
2. verifies compiler labels in the `ZydisInfo` ELF and extracts static ICF GT;
3. runs the native Zydis test through Pin/MyPinTool to collect dynamic ICF GT;
4. strips a copy and proves its `.text` bytes did not change;
5. constructs the heterogeneous angr/DGL ACFG from the stripped copy; and
6. verifies that every normalized dynamic pair is covered by static GT and that
   the graph contains code/data nodes and the required edge relations.

A failure returns a nonzero status. Success ends with:

```text
E1 PASS: Zydis static GT, dynamic GT, and stripped-binary heterogeneous ACFG verified
```

## Results

Copy the evidence and remove the stopped container:

```bash
docker cp icflownet-e1:/output/zydis ./e1-output
docker rm icflownet-e1
cat e1-output/verification.json
```

The verified result has 77 dynamically observed ICF pairs covered by 93 static
GT pairs. The graph has 546 code nodes, 249 data nodes, and 2,273 edges.
`verification.json` is the concise report; `run.log`, the package build/test
logs, labeled and stripped ELFs, GT JSON files, and compressed graph are kept in
the same directory.
