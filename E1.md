# E1 Combined Docker Experiment

This repository includes a Docker-only functional experiment for ICFlowNet
claim C1. It compiles the existing `testlink.cpp` with the custom LLVM, collects
dynamic indirect-control-flow ground truth with MyPinTool, extracts compiler
label-derived static ground truth, strips a copy of the ELF, and constructs and
checks a heterogeneous angr/DGL ACFG from the stripped copy.

No LLM test-generation functionality is used by E1.

## Image contents

`Dockerfile.e1` extends the published
`icflow-dynamic-collection:prebuilt` image with:

- the exact `graphenv.yml` from ICFlowNet;
- the static GT and graph source from ICFlowNet commit
  `c8dc19514f47bcc15b1b59348eaac058bfa63ce0`;
- the PalmTree vocabulary and checkpoint;
- `e1/run_e1.sh` and `e1/verify_e1.py`.

The ICFlowNet source subset is vendored because its repository is private and
reviewers must not need repository credentials.

## Build locally

First load the published base image as documented in `README.md`. Then run:

```bash
docker build -f Dockerfile.e1 -t icflownet-e1:local .
```

The graph environment is large because `graphenv.yml` reproduces the paper's
CUDA-enabled PyTorch and DGL stack. E1 itself sets `PALMTREE_USE_CUDA=0`, so its
runtime check does not require a GPU.

## Run and verify

```bash
docker volume create icflownet-e1-output

docker run --rm --init \
  --cap-add=SYS_PTRACE \
  --security-opt seccomp=unconfined \
  -v icflownet-e1-output:/output \
  icflownet-e1:local \
  /opt/icflownet-e1/run_e1.sh \
    --sample testlink \
    --output /output/testlink
```

The command exits nonzero when a check fails. Its final success line is:

```text
E1 PASS: static GT, dynamic GT, and stripped-binary heterogeneous ACFG verified for testlink
```

Important outputs include:

```text
/output/testlink/
├── dynamic/testlink_icall.json
├── dynamic/testlink_ijump.json
├── labeled/testlink
├── stripped/testlink
├── proof/
├── static/graph/0.graph.gz
├── static/res/testlink/
├── verification.json
├── versions.txt
└── run.log
```

`verification.json` records the normalized static/dynamic pair comparison,
`.text` hash, graph hash, node counts, and per-relation edge counts.

## CI image

The `E1 combined Docker image` workflow downloads and verifies `docker-v1`,
builds `Dockerfile.e1`, runs the full experiment, uploads the small verification
outputs, and pushes the tested image to:

```text
ghcr.io/ryan-hub-bit/icflow-dynamic-collection:e1
```

GitHub Container Registry packages may initially be private. Set the package
visibility to public before giving the pull command to anonymous reviewers.
